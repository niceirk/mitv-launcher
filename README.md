# Главный экран для Android TV

Свой лаунчер для телевизоров Xiaomi и других на Android TV 8.0+: полка в духе Apple TV, два ряда приложений,
погода, новости BBC/DW/Meduza с новостью дня и срочными, сообщения Telegram с голосовым ответом,
таймер сна, кнопка VPN (если установлен v2rayTun). Тяжёлых эффектов нет — рассчитан на слабые телевизоры.

## Установка

**С компьютером (5 минут, всё включится сразу).** На телевизоре: Настройки → Об устройстве → 7 раз по «Сборка»,
затем «Для разработчиков» → «Отладка по сети». На компьютере с `adb`:

```
./tools/setup-tv.sh <IP телевизора>
```

**Без компьютера.** Скачайте `launcher.apk` из [последнего релиза](https://github.com/niceirk/mitv-launcher/releases/latest)
на телевизор (например, приложением Downloader) и установите. Затем в лаунчере: шестерёнка → «Разрешения» — там видно,
что включено; OK открывает нужный экран телевизора. Часть разрешений на некоторых моделях включается только с компьютера
(таймер сна — всегда).

## Настройки в самом лаунчере

Шестерёнка сверху: город погоды, новости (смена, срочные), текст сообщений Telegram, скрытые приложения, разрешения,
обновление. Удержание OK на плитке — переместить или скрыть приложение.

## Обновление

Шестерёнка → «Обновление»: лаунчер сам скачает новую версию с GitHub, телевизор попросит подтвердить установку.
Раз в сутки лаунчер проверяет обновления сам.

## Для разработчика

Kotlin без androidx, сборка: `./gradlew assembleRelease`. Все версии подписываются одним ключом
`~/.config/mitv-launcher/sign.keystore` (в репозиторий не входит) — без него обновление поверх не встанет.
Релиз: тег `v<versionCode>`, файл `launcher.apk`. Макеты всех экранов — `design/states.html`, значки — `design/icons.html`
(код значков `GlyphDefs.kt` генерируется из макета).
